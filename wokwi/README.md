# Wokwi

1. Create an ESP32 DevKit project in Wokwi.
2. Replace its `diagram.json` with the provided file.
3. Copy `firmware/main.ino` and `firmware/model.h` into the Wokwi sketch.
4. Add the libraries listed in `firmware/libraries.txt`.
5. Set your ThingsBoard token in `main.ino`.
6. Run.

For the first test you can leave ThingsBoard disconnected and verify sensor/relay/LED behavior in Serial Monitor.
